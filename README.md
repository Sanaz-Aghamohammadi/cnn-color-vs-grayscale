# CNN Color vs Grayscale Input

## Description

This project explores how different grayscale conversion methods affect CNN performance.

Several grayscale techniques are implemented, ranging from simple methods to more physically and perceptually meaningful approaches.

---

## Dataset

We use the **102 Category Flower Dataset**.

Dataset structure:
- `train` and `valid`: images organized into class folders
- `test`: images without class labels
